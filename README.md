## 5x、20x 到底指什么：两层限制，倍数只管一层

Claude 的用量限制是两层的，只看倍数容易高估自己拿到的额度。

第一层是 **5 小时滚动会话窗口**。聊天、跑任务、用 Claude Code 都在消耗这个窗口里的额度，旧的消耗滚出窗口后额度恢复。倍数只作用于这一层：Max 5x 在每个窗口里有 Pro 5 倍的额度，Max 20x 是 20 倍。

第二层是**每周限额**，跨所有模型计算。它不按你开始使用的时间重置，而是按账号分配的固定时间每周恢复，具体时间在设置的 Usage 页面能看到。这一层不随倍数等比放大——对每天跑长时间 Claude Code 会话的人来说，周限额往往才是先碰到的那堵墙。

另外有第三方实测提到，不同模型的用量是分开计数的，部分高端模型在 Max 上还有单独的周用量比例限制。官方没有公布具体数字，这部分以你账号后台显示为准。

还有一点值得记住：所有使用方式共享同一个额度池。网页版、桌面端、手机 App、Cowork 和 Claude Code 消耗的是同一份额度。上午跑了几小时代码，下午聊天的余量就会少一截。

顺带说下限额政策的变动：官方今年 5 月把 Claude Code 的 5 小时限额翻了一倍，同时取消了 Pro 和 Max 的高峰时段限流；而在 3 月，高峰时段的额度消耗曾一度更快。这东西一直在调，下单前看一眼官方公告不算多余。

## Max 5x 和 Max 20x：功能一样，差的只有额度

这点很多人没意识到：两档的功能清单完全一致。同样的模型、同样的上下文窗口、同样的高峰期优先权、同样的新功能抢先体验。多花 100 美元买到的只有容量，不是任何新功能。

所以怎么选，本质是用量问题。官方从不公布具体消息条数，网上流传的数字全是社区估算——比如 Pro 在 5 小时窗口内大约能处理 40 到 45 条复杂任务消息，Max 5x 约 225 条，Max 20x 约 900 条。这些数字随模型选择、消息长度、是否开启扩展思考大幅波动，当量级参考可以，当承诺不行。

有一条账是确定的。按比例算：Max 5x 花 5 倍的钱买 5 倍额度，单条消息成本和 Pro 持平；Max 20x 花 10 倍的钱买 20 倍额度，单条成本只有 Pro 的一半。如果你确定自己会长期重度使用，20x 反而是单位成本最低的档位。

实际使用中的分界线大致是：聊天为主、每周用几次 Claude Code，5x 足够；每天数小时泡在 Claude Code 里，或者并行跑多个会话，才需要考虑 20x。两者之间的情况，大多用不上 200 美元那档。

顺带纠正一个常见误解：Claude Code 和 Cowork 并不是 Max 独占，Pro 用户也能用。Max 的差异始终在额度和优先级上。

## Pro 还是 Max：数一数你每周撞几次限额

判断标准其实只有一条：Pro 的限额多久打断你一次。

**留在 Pro（20 美元）的情况：**

- 一周撞不到两次限额
- 用量一阵一阵的，中间有低强度日
- 主要用来写作、查资料、处理文档，偶尔写代码

**升 Max 5x（100 美元）的情况：**

- 每周都被限额打断，等重置的时间开始影响正经工作
- Claude Code 用得勤，大型代码库的会话动不动跑很久
- 80 美元差价，低于你每周等限额浪费掉的时间成本

**升 Max 20x（200 美元）的情况：**

- 几乎每天撞限额，Claude Code 是全天主力工具
- 并行跑多个任务，Claude Code 和 Cowork 同时开工
- 接的是不能耽搁的客户项目，delay 不可接受

有测评算过一笔账：按每小时 150 美元计费的开发者，如果每周因为等限额重置损失 30 分钟，一个月就是 300 美元的产能缺口，100 美元的 Max 5x 直接回本。这笔账成不成立，取决于你的时薪和撞限额的频率，代入自己的数字就有答案。

建议和大多数测评一致：先在 Pro 上观察几周，确认自己真的在反复等限额再升级。后悔的人几乎都是预防性升级的——为想象中的用量多付了钱。

## 升级、降级，和几个容易被忽略的细节

- **升级立即生效**，按当前计费周期的剩余时间补差价；已领取月度 API 额度的，升级后马上按比例补发差额
- **降级在下一个计费周期生效**，本周期内保留原档位权益
- 从 Pro 年付转 Max：如果年付剩余金额高于 Max 月价，差额以账户抵扣金返还，抵扣后续订阅费用；前提是两次订阅的账单地址一致，否则得先取消旧订阅等它到期
- 撞限额时有三个选择：等重置、用 `/model` 切换更轻量的模型、开启 usage credits 按 API 标准费率继续用（预付制，可设月度上限，单日兑换上限 2000 美元）
- 官方还有“限额重置”机制，可以立即把 5 小时会话限额或周限额恢复满额

模型选择对额度的影响比很多人想的大。高阶模型每轮消耗是轻量模型的数倍，扩展思考更是一条回复就能吃掉普通回复十倍以上的 token。任务之间清一下上下文，长期任务拆开跑，同样的额度能干多不少活。

**Claude Max 包含 API 吗？**
订阅本身覆盖 Claude 各端 App 和 Claude Code 的使用。官方帮助文档提到 Max 订阅每月附带一定 Claude API 额度，超出部分按 token 独立计费。把 Max 当成“API 钱包”是误解，它不是。

**有免费或打折的 Claude Max 吗？**

**撞到限额怎么办？**
